# MindCore 0.4.0

Persona와 다시 이어지는 경험을 다듬었습니다.

## 변경 사항

- Persona DB credential의 줄바꿈 처리 오류를 수정했습니다.
- 초기 설정과 앱 내부에 **Feedback**을 추가했습니다.
- 업데이트 권장, 나중에 선택, 업데이트 내용 보기를 추가했습니다.
- 현재 버전의 업데이트 내용은 인터넷 없이도 볼 수 있습니다.

## 자세히 보기

[업데이트 공지](https://github.com/Luska-catjun/MINDCORE/releases)
